# Bifrost · Instagram

Repositório do agente de social media da Bifrost (@bifrosttech).

- `AGENTE.md`: o processo que o agente segue a cada execução
- `marca/`: identidade visual, voz e formatos
- `ferramentas/`: CSS da marca, o render de HTML para JPG e a busca de fotos reais (`foto.py`, Pexels/Unsplash)
- `modelos/`: modelos das três famílias visuais (clássica, foto, editorial) e dos stories com foto
- `posts/`: as artes publicadas (servidas publicamente para o Metricool)
- `historico.md` e `aprendizados.md`: a memória do agente
